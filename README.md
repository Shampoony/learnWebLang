# Lingua

Адаптивный сайт для изучения немецкого и словацкого с русским интерфейсом. Начальная точка — A1 для обоих языков.

## Запуск

Нужен Node.js 20+ (проверено с Node.js 24). Внешних зависимостей и обязательных ключей API нет.

```sh
cd /workspace/learnWebLang
npm run dev
```

Сервер слушает `0.0.0.0:3000`. Другой порт: `PORT=3001 npm run dev`. Остановить — Ctrl+C. Приложение целиком клиентское; сервер отдаёт только публичные ресурсы. Для production можно использовать любой статический хостинг, развернув `index.html`, `style.css`, `app.js`, `data.js`, `lessons-extra.js`, `exam-data.js` и `exam-ui.js` в корне сайта.

## Возможности

- Немецкий и словацкий: по 32 авторских урока, по восемь на каждый уровень A1, A2, B1, B2.
- 384 словарные карточки и 448 упражнений: выбор ответа, грамматические вопросы и самостоятельный ввод слова.
- Короткие пояснения, прохождение при результате не ниже 70%, повторная попытка.
- Словарь с поиском, фильтром уровня и добавлением в повторение.
- Активное вспоминание: сначала слово, затем раскрытие перевода и самооценка.
- Интервалы успешного повторения: 1, 2, 4, 8, 16, 30 дней. Ошибка — повтор через 10 минут. Самооценка не является объективной проверкой знания.
- Сохранение прогресса в localStorage. Без аккаунта, сервера данных и синхронизации устройств. Удаление данных браузера удаляет прогресс.
- Озвучивание Web Speech API при наличии соответствующего системного голоса. Без голосового пакета показывается сообщение; приложение остаётся работоспособным.
- Светлая и тёмная темы. Первый выбор следует системной теме, ручной выбор сохраняется.
- Мобильная навигация, клавиатурное управление, диалог с удержанием фокуса и закрытием через Escape.

## Итоговые тесты A1–B2

В конце каждого уровня доступны 8 авторских тестов (четыре уровня × два языка). Все тесты можно открыть сразу для диагностики, без искусственной блокировки по прогрессу уроков.

В каждой попытке:

- 24 задания: 8 грамматических, 8 лексических, 4 на чтение оригинального текста, 4 на понимание озвученного сообщения.
- Письменная работа с ориентиром объёма по уровню и отдельной самооценкой четырёх критериев.
- Устные задания и место для тезисов. Запись микрофона не производится. Качество речи автоматически не оценивается.
- Таймер 30/45/60/75 минут для A1/A2/B1/B2. Закрытие диалога или вкладки не останавливает время. Просроченная попытка завершается при возобновлении.
- Автосохранение ответов, текста и самооценки; результаты последних 10 попыток каждого теста; экспорт работы и разбора в `.txt`.
- Разбор доступен после сдачи. Пропуски дают 0 баллов. Порог автоматической части: не менее 70% суммарно и не менее 50% в каждом разделе, включая выполненное аудирование без открытой расшифровки.

Аудио генерируется голосом Web Speech API на устройстве, а не воспроизводит запись носителя. При отсутствии голоса доступна расшифровка для практики; её открытие либо отсутствие полного прослушивания отменяет зачёт аудирования. Исправность событий воспроизведения проверена браузерным тестом с имитацией голосов; качество реальных голосов зависит от устройства.

Эти пороги и длительность принадлежат тренажёру, а не Goethe, telc, ECL или CEFR. Даже успешная автопроверка не подтверждает языковой уровень: письмо и речь нуждаются в независимой оценке преподавателя. На странице источников есть ссылки на официальные образцы Goethe и ECL. Подборка и материалы сайта не копируют официальный экзамен.

## Содержание и границы

Это стартовая учебная коллекция, а не законченный курс достижения B2. Метки уровней указывают приблизительную сложность материала и не являются сертификацией CEFR. Модули не заменяют полный учебник, разговорную практику, развёрнутое аудирование и проверку письменных работ преподавателем.

На странице «Методика и источники» приведены CEFR (Council of Europe), рекомендуемые Netzwerk neu, Aspekte neu, Grammatik aktiv, Krížom-krážom, Goethe-Institut, DW и Slovake.eu; также статьи Roediger & Karpicke (2006) и Cepeda et al. (2006). Упражнения написаны специально для сайта, не скопированы из этих изданий и не проверены их авторами. Перед выпуском большого курса нужен редактор — специалист по каждому языку.

## Проверка

```sh
npm test
```

Проверяются покрытие уровней, валидность всех 448 заданий уроков и 192 заданий тестов, задания с вводом, расписание повторений, экзаменационные пороги, ограничения зачёта аудирования и HTTP-сервер, включая закрытие доступа к непубличным файлам.

В ходе разработки отдельно выполнены браузерные проверки Chromium через Playwright: прохождение урока, неверный ответ, письменные задания, сохранение после перезагрузки, фильтры, смена языка и карточки повторения. Дополнительно пройдены все восемь итоговых тестов (192 ответа), проверены сохранение письма и самооценки, скачивание результата, таймер и истечение времени, восстановление попытки, ограничения расшифровки и сохранение темы. Экраны проверены на ширинах 320, 390, 768, 1440 пикселей.

## Структура

- `data.js` — языки, модули, словарь, генерация вопросов и алгоритм повторения.
- `lessons-extra.js` — дополнительные 40 уроков.
- `exam-data.js` — восемь итоговых тестов, тексты, задания и оценивание.
- `exam-ui.js` — таймер, черновики, результаты и экспорт экзаменационных работ.
- `app.js` — экраны и взаимодействия.
- `style.css` — адаптивные стили и иллюстрации без внешних изображений или шрифтов.
- `server.mjs` — сервер разработки без сторонних зависимостей.
- `tests/` — автоматические проверки на встроенном Node.js test runner.
